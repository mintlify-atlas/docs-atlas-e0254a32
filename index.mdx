MaaNTE is an open-source automation assistant for the game **Neverness to Everness** (NTE / 异环). It uses image recognition via [MaaFramework](https://github.com/MaaXYZ/MaaFramework) to automate repetitive in-game tasks, including fishing, coffee brewing, café revenue collection, and real-time event handling — freeing you to focus on the parts of the game you enjoy.

<Warning>
  MaaNTE is in early development. Features are actively evolving. Always download from the [official GitHub releases](https://github.com/1bananachicken/MaaNTE/releases) — third-party redistributions may contain malware and are never up to date.
</Warning>

## Get started

<Steps>
  <Step title="Check requirements">
    Make sure your system meets the [requirements](/requirements): Windows, Python 3.11+, and the game running at 1280×720 in windowed mode.
  </Step>
  <Step title="Download the release">
    Go to the [GitHub releases page](https://github.com/1bananachicken/MaaNTE/releases) and download the latest release package. Always use the official source.
  </Step>
  <Step title="Run as administrator">
    Extract the package and launch **MaaNTE.exe** as administrator. Administrator rights are required for input control.
  </Step>
  <Step title="Select your tasks">
    Use the GUI to enable the automation tasks you want — fishing, coffee brewing, revenue collection, or real-time assistance — then start.
  </Step>
</Steps>
