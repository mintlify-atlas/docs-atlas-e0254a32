MaaNTE is a Windows automation assistant for **Neverness to Everness** (NTE / 异环). It uses [MaaFramework](https://github.com/MaaXYZ/MaaFramework) — an image recognition automation framework — to detect in-game states and perform actions on your behalf, so you can automate repetitive tasks without modifying any game files.

## What MaaNTE automates

MaaNTE covers four main automation areas in Neverness to Everness:

- **Auto Fishing** — casts, monitors the fishing slider, reels in catches, sells the haul, and restocks bait. The fishing algorithm supports up to 120 FPS.
- **Auto Coffee Brewing** — runs full café brewing loops and dismisses customers automatically. Requires mouse input mode set to "Seize."
- **Café Revenue Collection** — collects café earnings and restocks inventory without manual interaction.
- **Real-Time Assist** — handles in-game events such as story prompts and teleport points as they appear.

## How it works

MaaNTE is built on two components:

- **MaaFramework** — the underlying image recognition engine that identifies UI elements, game states, and interactive objects on screen.
- **MFAAvalonia** — an Avalonia-based GUI wrapper that lets you configure and launch MaaFramework tasks without writing code.

The agent layer is written in Python and runs in a virtual environment that is created automatically on first launch. All required dependencies (`maafw`, `loguru`, `pillow`, `pytz`, `requests`, `opencv-python`) are installed from `requirements.txt` without any manual steps.
