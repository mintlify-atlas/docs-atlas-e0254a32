---
title: "Quickstart: Run MaaNTE for the First Time on Windows"
description: "Download MaaNTE, extract the release package, and run your first automation task in Neverness to Everness — from zero to running in minutes."
---

This guide walks you through everything you need to go from a fresh download to running your first automation task in Neverness to Everness. Before you begin, confirm your system meets the [requirements](/requirements).

<Warning>
  Your antivirus software may flag MaaNTE because it uses Win32 input control to interact with the game. If installation is blocked or files are quarantined, add an exception for the MaaNTE folder or temporarily disable real-time protection.
</Warning>

<Steps>
  <Step title="Check requirements">
    Make sure your system is ready before downloading. You need Windows with administrator access, and Neverness to Everness installed and able to run at **1280×720 in windowed mode**.

    See the full [requirements](/requirements) page for details.
  </Step>

  <Step title="Download from GitHub releases">
    Go to the official releases page and download the latest release package:

    [https://github.com/1bananachicken/MaaNTE/releases](https://github.com/1bananachicken/MaaNTE/releases)

    <Warning>
      Only download from the official GitHub releases page. Third-party mirrors may contain malware.
    </Warning>
  </Step>

  <Step title="Extract the package">
    Extract the downloaded archive to a folder on your system.

    <Warning>
      Do not place MaaNTE in a folder path that contains Chinese characters or other full-width characters. For example, `C:\Tools\MaaNTE` is fine; `C:\工具\MaaNTE` is not. Paths with non-ASCII characters will cause the tool to fail.
    </Warning>
  </Step>

  <Step title="Launch MaaNTE.exe as administrator">
    Right-click **MaaNTE.exe** and select **Run as administrator**. Administrator rights are required for Win32 input control, which MaaNTE uses to interact with the game.

    On first launch, MaaNTE automatically creates a Python virtual environment and installs its dependencies from `requirements.txt`. This takes a moment and only happens once.
  </Step>

  <Step title="Start the game in windowed 1280×720 mode">
    Launch Neverness to Everness and set it to run in **windowed mode** at a resolution of exactly **1280×720**. MaaNTE's image recognition is calibrated for this resolution — other sizes will cause tasks to fail.
  </Step>

  <Step title="Select a task in the GUI">
    In the MFAAvalonia GUI, choose the task you want to run — for example, **Fishing Task**. Review any task-specific settings before continuing.

    <Note>
      Coffee brewing requires the mouse input mode to be set to **Seize** in the MaaFramework controller settings. In Seize mode, MaaNTE temporarily takes over your mouse during brewing cycles.
    </Note>
  </Step>

  <Step title="Click Start">
    Click **Start** to begin the automation. MaaNTE will take over the configured tasks and run them automatically.
  </Step>
</Steps>

## Tips

<Tip>
  Always run MaaNTE as administrator. If you forget, input control will fail silently and tasks will not progress.
</Tip>

<Tip>
  Use an English-only file path with no spaces or special characters. For example, `C:\MaaNTE` or `D:\Tools\MaaNTE` are both safe choices.
</Tip>

## "Mirror not supported" pop-up

If you see a pop-up in the bottom-right corner saying **Mirror not supported**, you can safely ignore it. This message appears because auto-update is not configured in the release build. It does not affect any automation functionality.
